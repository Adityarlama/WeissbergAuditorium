## 🎛️ Weissberg Auditorium AV System Overhaul  

**Beloit Powerhouse — Independent Project**  
**August 2024 – December 2024**  
**Project Deliverable:** [AV System Instructional Guide (2 pages)](https://imgur.com/gallery/weissberg-auditorium-instructional-sheets-u9Afqkr)

### 📌 Overview  
Led a full usability and reliability improvement initiative for the Weissberg Auditorium’s audiovisual system at the request of the Student Union Director. The auditorium had long-standing issues with controls, cabling, audio clarity, and equipment accessibility, impacting both student and administrative events.

### 🛠️ Key Contributions  
- Reorganized and optimized physical AV hardware layout to streamline operation and reduce setup time.  
- Implemented comprehensive cable management and equipment labeling to standardize system workflows.  
- Integrated Crestron control panels, lighting presets, and microphone systems into a cohesive, user-friendly configuration.  
- Resolved recurring functionality issues that had caused frequent interruptions during events.  

### 📄 Documentation Produced  
- Authored a detailed **two-page AV System User Guide** with step-by-step instructions and visual references.  
- Contributed the guide to the campus IT knowledge base to improve accessibility and reduce support dependency.

### 🎯 Impact  
- Significantly improved system usability for student groups, staff, and event organizers.  
- Reduced AV-related support requests and troubleshooting time for IT staff.  
- Enhanced reliability of auditorium operations for classes, presentations, and campus events.
